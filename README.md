Mr. Mario — Plumbing Services Landing Page

A fun, themed landing page for a plumbing service, featuring Mario and Luigi as the "plumbers of the Mushroom Kingdom." Includes a video background, contact form, and WhatsApp quick-contact button.

Mostrar Imagem

✨ Features
Header with logo and navigation (Home, Fale Conosco, Nossos Serviços)
Hero section with a Mario-themed logo, service description, and "Entre em Contato" call-to-action
Background video with a dark gradient overlay for readability
Character illustration of Mario and Luigi as plumbers
Floating WhatsApp button for quick contact
Slide-in contact form with name, email, and message fields, submitted via Formcarry
Interactive header links that highlight (grow in size) when clicked
Fully responsive design for mobile devices
